## Findings

### Critical

None reported by GitHub Dependabot.

### High

The current lane now uses Home Assistant 2026.7.4 and `aiohttp` 3.14.3. This removes the `aiohttp` findings from the installed current-lane environment.

The committed lockfile must still contain the Home Assistant 2025.1.0 dependency graph for the documented Python 3.12 compatibility lane. GitHub therefore continues to report high-severity findings against older locked versions of `aiohttp`, `cryptography`, `homeassistant`, `orjson`, `pillow`, `pyjwt`, `pyopenssl`, and `urllib3`.

### Medium

The minimum compatibility lane also retains reported findings in `jinja2`, `pycares`, `pytest`, `requests`, and `uv`. `pycares` 4.5.0 is an explicit compatibility pin because newer releases break Home Assistant 2025.1's `aiodns` cleanup under its test harness.

The current Home Assistant 2026.7.4 release pins Pillow 12.2.0 and PyJWT 2.12.1. `pip-audit` reports fixes in Pillow 12.3.0 and PyJWT 2.13.0, but overriding Home Assistant's exact runtime pins would make this repository's tests unrepresentative of that Home Assistant release.

### Low

Low-severity findings remain in the minimum Home Assistant 2025.1.0 dependency graph.

## Failed Updates

A complete alert closure cannot be made as a lockfile-only refresh while preserving Home Assistant 2025.1.0 support:

- The Home Assistant advisory affecting versions before 2026.6.0 requires Home Assistant 2026.6.0 or later.
- Home Assistant 2026.6.0 requires Python 3.14.2 or later, while the minimum lane deliberately verifies Python 3.12.
- Updating `pycares` independently would undo the compatibility fix documented beside its pin.
- Pillow and PyJWT fixes for the current lane are not yet present in the latest Home Assistant release's exact dependency set.

These are test-only dependencies and are not runtime dependencies of the integration package. The remaining alerts should not be dismissed as fixed; they require a separate decision to retire the minimum compatibility lane or an upstream Home Assistant release carrying the newer pins.
